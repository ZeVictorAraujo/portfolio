## Projetos pessoais

Desenvolvi o **Personal.fin**, uma aplicação para acompanhar receitas, despesas e faturas em um só lugar. O projeto utiliza Next.js, Material UI, Supabase e TypeScript, com autenticação e compartilhamento com permissões de leitura e edição.

[Acessar o Personal.fin](https://personalfin.zevictoraraujo.com.br/) · [Ver o código](https://github.com/ZeVictorAraujo/personal-finance)

Também desenvolvo o **ZevNucleo**, um sistema próprio para organizar a rotina de TI, inspirado nas funcionalidades do GLPI. O projeto utiliza Next.js, TypeScript, Material UI, PostgreSQL e Prisma, com login privado, cadastro de chamados, filtros e histórico de atendimento.

[Acessar o ZevNucleo](https://zevnucleo.tech/) · [Ver o código](https://github.com/ZeVictorAraujo/ZevNucleo)
